# 검증 범위

## 실행 검증 (최종 해시 디스크, 헤드리스 ClownMDEmu libretro)
- 콜드 부팅 → RIOT 로고 → 오프닝 → 타이틀 화면(한글 로고, 영어 저작권 표기 유지, 시작 안내 문구의 두 깜박임 상태).
- 제1화 장 제목 카드, 제1화 도입부 대사와 나레이션, 정보창(INFORMATION) 라벨, 우측 하트 로고.
- 직접 플레이하며 발견한 미번역 부분(정보창, 장 제목, 스크립트 기호가 섞인 대사 등)을 추가 패치하고 재확인.
- 검증용 에뮬레이터는 모두 종료했습니다.

## 정적 검증
- 빌드 결과 번역 누락 0, 길이 초과 0, 오류 0.
- 모든 대사 줄 13칸·한 페이지 4줄 이내.
- 하트 로고가 들어 있는 파일 전체 검사(맵 파일 89개 모두 교체, 다른 파일에는 없음).
- xdelta를 원본 CHD에 적용한 결과가 릴리즈용 한글 CHD와 바이트 단위로 같음.

## 미검증
- 제2화 이후 전편 실제 플레이와 모든 이벤트·엔딩 도달.
- 디스크 헤더 게임 이름의 실제 표시(헤더를 Shift-JIS로 읽는 프로그램에서는 깨져 보일 수 있음).
- 실기(실제 메가 CD) 및 다른 에뮬레이터.
