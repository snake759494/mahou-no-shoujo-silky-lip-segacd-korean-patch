# 기술 설명

- **디스크**: 트랙 1(Mode 1 데이터) ISO의 파일을 같은 섹터 범위 안에서 교체하고 EDC/ECC를 재계산합니다(`disc.py`, `cdsector.py`). 오디오 트랙은 그대로입니다.
- **문자**: 게임은 Shift-JIS 2바이트 코드와 LOAD 파일의 18바이트 단위 한자 글꼴을 씁니다. JIS 제1수준 한자 2,350칸을 KS X 1001 한글 음절 2,350자로 덮어써 코드만 바꾸면 한글이 나오게 했습니다(`font.py`, 나눔스퀘어 네오 Regular).
- **문자열**: 각 실행 파일에서 Shift-JIS 문자열과 이를 가리키는 32비트 포인터(워드 RAM 0x200000 기준)를 찾아, 연속 블록 안에서 재배치하고 포인터를 갱신합니다(`build.py`). 포인터가 없는 문자열은 원래 길이 안에 맞춥니다.
- **그림 글자**: 장 제목 카드(`titlecard.py`), 정보창 라벨(`panel.py`), 타이틀 로고(`titlelogo.py`), 하트 로고(`hudlogo.py`).
- **LZSS**: 1KB 창(0x000~0x2FF는 0, 0x300~0x3FF는 0xFF), 앞 2바이트가 출력 크기, 플래그는 MSB부터, 참조는 2바이트 LE(하위 10비트 절대 위치, 상위 6비트 길이). `lzss.py`는 원본보다 약간 작게 압축해 원래 자리에 넣습니다.
- **헤더**: ISO 0x120(48바이트) 국내용 게임 이름을 UTF-8 한글로 바꿨습니다.
